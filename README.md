# JobOps

AI-powered ATS Resume Generator and Job Matching Platform.

## Features

- ATS Resume Generation
- Cover Letter Generation
- Job Description Analysis
- Skill Extraction
- Job Matching
- Batch Matching
- Resume Personalization
- FastAPI Backend
- Docker Support

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- Ollama
- Docker
- PostgreSQL (future)
- Sentence Transformers

## Run

```bash
docker compose up --build
```

Swagger:

```
http://localhost:8000/docs
```
